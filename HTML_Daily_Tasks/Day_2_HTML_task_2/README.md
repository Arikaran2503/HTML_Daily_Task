# College Admission Form

A simple **College Admission Form** created using HTML.

## Features

- Applicant full name
- Date of birth
- Email address
- Phone number
- Permanent address
- Country selection
- Course selection
- Joining date
- HSLC certificate upload
- Apply Now button

## Technologies Used

- HTML5

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Fill in the admission form.
