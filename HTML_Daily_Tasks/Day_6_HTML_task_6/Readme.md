# 🌏 Explore India — Day 6 HTML Task

A simple **HTML-only travel website** created as part of the HTML Daily Task series. This project demonstrates the use of semantic HTML elements to build a structured travel destination webpage without CSS or JavaScript.

## 📌 Project Overview

**Explore India** is a travel information webpage that introduces visitors to popular Indian destinations, places to visit, activities, travel budgets, accommodation options, travel checklists, and a travel enquiry form.

The page focuses on practicing:

* Semantic HTML
* Headings and paragraphs
* Images and figures
* Navigation links
* Tables
* Ordered and unordered lists
* Forms and form controls
* `<details>` and `<summary>`
* HTML5 semantic elements
* Internal page navigation

## ✨ Features

### 🏠 Home Section

* Introduction to the website
* Welcome message
* Indian destination image
* Travel quote
* Internal navigation

### 📍 Popular Destinations

The webpage highlights:

1. **Goa** 🏖️
2. **Kerala** 🌴
3. **Rajasthan** 🏰

Each destination contains:

* Destination image
* Description
* Best travel season
* Link to detailed information

### 🏛️ Must-Visit Places

A table provides information about attractions such as:

* Baga Beach
* Alleppey Backwaters
* Amber Fort
* India Gate
* Meenakshi Temple

### 🎯 Things to Do

Activities are organized into categories:

* Beach Activities
* Adventure
* Cultural Experiences

### 🔎 Destination Information

Expandable `<details>` sections provide additional travel information for:

* Goa
* Kerala
* Rajasthan

### 💰 Estimated Travel Budget

A comparison table includes estimated:

* Hotel costs
* Food costs
* Transportation costs
* Activity costs

The budget is divided into:

* Budget
* Standard
* Luxury

### 🏨 Accommodation

The website lists different types of stays:

* Budget Hotels
* Beach Resorts
* Luxury Hotels
* Homestays
* Houseboats

### 🎒 Travel Checklist

Visitors can check off essential travel items such as:

* Passport / ID
* Clothes
* Camera
* Medicines
* Phone Charger
* Travel Documents

### 📩 Travel Enquiry Form

The enquiry form collects:

* Full Name
* Email
* Destination
* Travel Date
* Number of Travelers
* Travel Message

It also includes **Submit** and **Reset** buttons.

## 🛠️ Technologies Used

* **HTML5**
* Semantic HTML elements
* HTML forms
* HTML tables
* External images from Unsplash

No CSS or JavaScript is used in this task.

## ▶️ How to Run

1. Download or clone the repository.
2. Open the `Day_6_HTML_task_6` folder.
3. Open `index.html` in any modern web browser.
4. Explore the different sections using the navigation links.
