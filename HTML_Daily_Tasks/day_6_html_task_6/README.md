# 🌏 Explore India – Travel Destination Website

A simple, responsive-ready **HTML travel website** that showcases beautiful destinations across India, including popular places, activities, travel budgets, accommodation options, and a travel enquiry form.

## 📌 About the Project

**Explore India** is a beginner-friendly travel website created using **HTML5**. It provides visitors with information about Indian destinations such as:

* 🏖️ Goa
* 🌴 Kerala
* 🏰 Rajasthan
* 🏛️ Delhi
* 🛕 Tamil Nadu

The project demonstrates the use of semantic HTML elements, images, tables, forms, navigation links, lists, and expandable content.

## ✨ Features

* 🌏 Attractive travel-themed homepage
* 📍 Popular destination section
* 🏛️ Must-visit places table
* 🎯 Activities and things to do
* 🔎 Expandable destination travel guides using `<details>`
* 💰 Estimated travel budget
* 🏨 Recommended accommodation types
* 🎒 Travel checklist
* 📩 Travel enquiry form
* 🧭 Internal navigation between sections
* 🖼️ Destination images from Unsplash
* ♿ Semantic HTML structure for better accessibility

1. Clone this repository:

```bash
git clone https://github.com/your-username/explore-india.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

That's it! 🎉

## 💰 Travel Budget

The website includes estimated daily costs for:

* Hotels
* Food
* Transportation
* Activities

These are sample estimates intended for demonstration purposes and may vary depending on location, season, and travel style.

## 📩 Enquiry Form

The website includes a travel enquiry form where users can enter:

* Full name
* Email
* Destination
* Travel date
* Number of travelers
* Travel requirements/message

> **Note:** The form is currently a front-end HTML form and does not have a backend for storing or processing submissions.
