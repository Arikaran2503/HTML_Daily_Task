# Day 3 - HTML Task 3

## SBI Online NEFT Transfer

This project is a simple HTML webpage that represents an **SBI Online NEFT Transfer** interface. The page is created using basic HTML elements such as forms, tables, radio buttons, input fields, dropdowns, and buttons.

## Project Overview

The webpage allows the user to:

* Select a bank account for transferring funds.
* View account number, account type, branch, and balance.
* Enter the transfer amount.
* Select the purpose of the transaction.
* Select an intra-bank beneficiary.
* View beneficiary account details and transaction limits.
* Select a payment option.
* Submit or cancel the transaction.

## Features

### 1. Account Selection

Displays the available account details in a table and provides a radio button for selecting an account.

### 2. Transfer Amount

Provides a number input field to enter the amount to be transferred.

### 3. Transfer Purpose

Provides a dropdown menu with different transaction purposes such as:

* Home loan
* Medical loan
* Educational loan

### 4. Beneficiary Selection

Displays intra-bank beneficiary details including:

* Account Number
* Beneficiary Name
* Branch
* Transfer Limit
* Change Button

### 5. Payment Options

The user can select one of the following payment options:

* Pay Now
* Schedule Later
* Standing Instruction

### 6. Submit and Cancel

The form contains **Submit** and **Cancel** buttons at the bottom of the page.
